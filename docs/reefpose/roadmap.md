# ReefPose roadmap

Updated: 2026-11-12

- Phase 1 — native ReefPose-S architecture, training, inference, checkpointing, and GPU
  engineering validation: complete.
- Phase 2A — provider-neutral training infrastructure and executable Workflow Builder:
  complete.
- Phase 2B — training and Model Hub GUI: complete.
- Phase 2C — general-purpose anatomical skeleton design and annotation integration:
  complete.
- Phase 3A — immutable held-out scientific evaluation for native ReefPose: complete.
- Phase 3B — asynchronous provider-neutral comparison, reports, Model Hub, and Workflow
  Builder: complete, subject to optional SLEAP runtime availability and real biological
  validation.
- Phase 4 — pose-aware multi-animal association, identity review, IDF1, and
  identity-switch analysis: complete for the deterministic, scientist-gated vertical
  slice, subject to real biological validation.
- Phase 5 — immutable anatomical measurement series, deterministic event counting,
  append-only scientist review, executable Workflow Builder, scientific exports, and the
  integrated Biological Movement Workspace: complete for the synthetic engineering
  vertical slice, subject to real biological validation.

- Phase 6 — independent reference revisions, automatic output scoring, development
  threshold locks, observer agreement, clustered uncertainty, scientific reports,
  and validation review. Engineering fixtures are available. Empirical validation is
  pending independently annotated recordings.

Recommended research milestone: freeze a blinded multi-species pilot with disjoint
training, development and test recording groups. Estimate observer variability,
calibration sensitivity, and event agreement, then run the locked held-out comparison.

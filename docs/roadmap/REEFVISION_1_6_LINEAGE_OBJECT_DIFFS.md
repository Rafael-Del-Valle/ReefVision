# ReefVision 1.6 — read-only same-name Alembic schema diagnostics

Two independently developed histories contain revision `0038`: the 1.1 scientific/environmental lineage and 1.6 QC lineage. A matching `alembic_version` string is **never** proof of equivalent schema or a safe upgrade. No applied migration is rewritten or automatically stamped.

`scripts/inspect_sqlite_lineage_16.py` now reports `schema_definition_sha256` (one SHA-256 fingerprint per SQLite table, index, view or trigger) and, when comparing independent read-only databases, `schema_comparison.changed_definitions` (matching object identities whose definitions differ). This closes a diagnostic blind spot where the structural fingerprints differed but both `only_in_*` inventories were empty. Digests hash canonical JSON of object type, name, owning table and DDL; **raw SQL, biological rows, annotation contents, and research observations are not emitted**. This is a diagnostic fingerprint, not a cryptographic attestation of historical migrations.

Run the inspector on **existing disposable offline backups**, with no live WAL/SHM/journal sidecars, using `python scripts/inspect_sqlite_lineage_16.py backup-16.sqlite --compare-to backup-11.sqlite --fail-on-lineage-collision --fail-on-integrity-error`. Exit code 2 blocks unsafe equivalence claims, but exit code 0 never authorizes auto-migration or researcher approval. The tool is not a Workflow Builder biological analysis node; existing persisted, typed QC workflows remain unchanged. Any future compatibility migration must preserve both actual lineage histories, all user scientific data and human review, with independent round-trip and Windows upgrade tests.

Regression coverage includes same-name changed table columns, same-name partial-index DDL with private literals, identical structures with different research observations, canonical equal stamps, read-only byte preservation and controlled collision failure. Full installed-Windows validation, independent reconciliation of Alembic 0038 and representative researcher acceptance remain release blockers.

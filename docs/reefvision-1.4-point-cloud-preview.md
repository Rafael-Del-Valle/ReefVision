# ReefVision 1.4 — provisional XYZ point-cloud preview

The standalone `POST /api/v1/projects/{project_id}/spatial/point-cloud-preview` endpoint and executable persisted `point_cloud_preview` Workflow Builder node share one bounded measurement engine.

Inputs are **either** up to 2,000 XYZ points **or** a vertex-only ASCII PLY 1.0 file with three floating-point XYZ properties. Binary PLY, color properties, polygon meshes, normals, and other attributes are deliberately unsupported in this first preview. The original PLY is passed as text; **no persistent 3D asset is created**.

Outputs include point count, duplicate-point QC, calibrated global-axis extents and diagonal, arithmetic centroid in the source coordinate frame, and scale-only uncertainties when supplied. Optional `point_index_pairs` (up to 32 pairs of distinct zero-based indices) returns calibrated straight-line chord distances and scale-only uncertainty for selected original input points. Pair indices are strictly integers and must be within bounds. Each chord includes `chord_distance_scale_interval_m` (lower/upper bounds) when scale uncertainty is provided; it is `null` when unknown. These are scale-only intervals, not statistical confidence intervals or biological branch lengths. These chords are not surface geodesics or biological branch lengths. An additional ordered-geometry SHA-256 fingerprint records the exact point order used for index selection; the existing order-independent geometry fingerprint is retained. The axis-aligned bounding-box **envelope** volume (m³) is the product of the three extents, **not** coral tissue volume or reconstructed occupied volume. Its scale-uncertainty interval applies the lower and upper scale factors cubically. Coplanar or collinear points have zero envelope volume, regardless of actual organism thickness. Surface area and branch length are **null**, not estimated from a point cloud. Scale evidence and exact geometry fingerprint are recorded, but calibration and coordinate registration are **not verified**. Dimensions are not anatomical branch measurements, and geometry fingerprints are not organism identities.

Both standalone API and saved-workflow artifacts remain `caller_supplied_unverified`. Do not promote to a verified scientific observation without human review and registration/calibration QC. Future work includes persistent 3D assets, large/binary clouds, interactive viewer, registration and longitudinal comparisons.

The preview also returns calibrated minimum and maximum XYZ coordinates in the **original source frame**. These axis-aligned bounds preserve negative coordinates and support future interactive camera framing; they are not registered geographic positions. Standalone API results and persisted Workflow Builder artifacts must agree on these bounds.

The arithmetic point-sample centroid also includes `arithmetic_centroid_in_source_frame_scale_interval_m` when relative scale uncertainty is supplied, with lower and upper limits sorted correctly for negative source coordinates. It is `null` when uncertainty is unknown. This interval propagates **scale uncertainty only**; it does not account for reconstruction error, point-sampling density, or unverified coordinate registration. A sample centroid is not a validated organism center of mass. The standalone and saved-workflow results must match.
